# DAT என்றால் என்ன?

DAT (Distributed Access Token) என்பது வழங்கும் சேவையும் சரிபார்க்கும் சேவையும் ஒரே சான்றிதழைப் பகிர்ந்து பயன்படுத்தும் அணுகல் டோக்கன் விவரக்குறிப்பாகும். சரிபார்க்கும்போது வழங்கும் சேவையையோ மத்திய அமர்வுச் சேமிப்பகத்தையோ மீண்டும் அணுகத் தேவையில்லாததால், சேவைகளுக்கிடையிலான இணைப்பைக் குறைத்து அங்கீகரிப்பு முடிவைப் பரிமாற முடியும்.

## கூறுகள்

### DAT

பயனர் அல்லது சேவை கோரிக்கையுடன் அனுப்பும் சரமாகும். இதில் காலாவதி நேரமும் சான்றிதழ் ID-ம் அடங்கும்; பொதுத் தரவையும் மறையாக்கப்பட்ட தரவையும் ஒன்றாகக் கொண்டிருக்கலாம்.

### சான்றிதழ்

DAT-ஐ உருவாக்கவும் சரிபார்க்கவும் தேவையான வழிமுறைகள், விசைகள் மற்றும் கால வரம்பு இதில் அடங்கும். சான்றிதழ் ID ஆன `cid` மாறாது; விசையை மாற்றும்போது புதிய `cid`-ஐப் பயன்படுத்தவும்.

### மேலாளர்

கிளையன்ட் நூலகத்தின் மேலாளர் சான்றிதழ்களைச் சேமித்து, தற்போது வழங்கக்கூடிய சான்றிதழால் DAT-ஐ உருவாக்கி, DAT-ன் `cid`-க்குப் பொருந்தும் சான்றிதழால் அதைச் சரிபார்க்கிறார்.

### DAT CMS

சான்றிதழ்களை உருவாக்கிச் சேமித்து, சேவைகளுக்கு வழங்கும் விருப்பத் தேர்வான சேவையாகும். வழங்கும் சேவைகளுக்கு முழுமையான சான்றிதழ்களையும், சரிபார்ப்பு மட்டும் செய்யும் சேவைகளுக்கு சரிபார்ப்பு-மட்டுமான சான்றிதழ்களையும் இதனால் வழங்க முடியும்.

வழங்கும் சேவை `plain` மற்றும் `secure` தரவைத் தீர்மானித்து DAT-ஐ உருவாக்குகிறது. சரிபார்க்கும் சேவை காலாவதி நேரம், கையொப்பம் மற்றும் மறையாக்கப்பட்ட உள்ளடக்கம் ஆகியவற்றைச் சரிபார்த்த பின் இரு தரவுப் பகுதிகளையும் பயன்பாட்டிற்கு வழங்குகிறது. `plain` கையொப்பமிடப்படும், ஆனால் மறையாக்கப்படாது; எனவே அதில் ரகசியம் அல்லது தனிப்பட்ட தகவலை வைக்காதீர்கள்.

## சான்றிதழ் மாறினாலும் ஏன் சரிபார்ப்பு சாத்தியம்?

புதிய சான்றிதழ் வழங்கக்கூடியதாகும்போது, அதன்பின் உருவாகும் DAT-கள் புதிய `cid`-ஐப் பயன்படுத்தும். ஏற்கனவே வழங்கப்பட்ட DAT-களின் TTL முடியும்வரை பழைய சான்றிதழ் சரிபார்ப்பிற்காக வைத்திருக்கப்படும். எனவே விசை மாற்றத்தையும் ஏற்கனவேயுள்ள டோக்கன்களின் சரிபார்ப்புக் காலத்தையும் ஒன்றாக இயக்க முடியும்.

## எந்தச் சூழல்களுக்கு இது பொருந்தும்?

- அங்கீகரிப்பையும் உண்மையான செயல்பாட்டையும் வெவ்வேறு சேவைகள் கையாளும் சூழல்கள்
- பல இயக்கச்சூழல்கள் ஒரே டோக்கனை வழங்கும் அல்லது சரிபார்க்கும் சூழல்கள்
- மத்திய அமர்வை வினவாமல் குறுகிய ஆயுளுள்ள அனுமதித் தகவலைப் பரிமாற விரும்பும் சூழல்கள்
- பொது வழிச்செலுத்தல் தகவலையும் பாதுகாக்க வேண்டிய தரவையும் ஒரே டோக்கனில் பிரித்து வைக்க வேண்டிய சூழல்கள்

DAT அனுமதிக் கொள்கையை வரையறுப்பதில்லை. DAT செல்லுபடியாக இருப்பதும் குறிப்பிட்ட கோரிக்கையைப் பயன்பாடு அனுமதிப்பதும் வெவ்வேறு முடிவுகளாகும்.
