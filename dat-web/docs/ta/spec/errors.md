# பிழைக் குறியீடுகள்

DAT செயலாக்கங்கள் மனிதரால் படிக்கக்கூடிய செய்தியைத் தவிர நிலையான பிழைக் குறியீடுகளை வழங்குகின்றன. நிரல் செய்திச் சரத்தை ஒப்பிடாமல் குறியீடு மற்றும் மீண்டும் முயல் வகையின்படி செயலைத் தீர்மானிக்கும்.

## வாசிப்பது எப்படி

```text
DAT_<பகுதி>_<காரணம்>
```

| முன்னொட்டு | பகுதி |
| --- | --- |
| `DAT_TOKEN_` | DAT சரம் மற்றும் காலாவதி |
| `DAT_CERT_` | சான்றிதழ் சரம் மற்றும் நிலை |
| `DAT_SIG_` | கையொப்பம் மற்றும் சரிபார்ப்பு |
| `DAT_CRYPTO_` | மறையாக்கம் மற்றும் மறைநீக்கம் |
| `DAT_KEY_` | விசை வடிவம் மற்றும் அனுமதி |
| `DAT_MANAGER_` | சான்றிதழ் மேலாளர் |
| `DAT_CONFIG_` | அழைப்பு வாதம் மற்றும் அமைப்பு |
| `DAT_INTERNAL_` | இயக்கச்சூழலின் உள் செயல்பாடு |
| `DAT_CMS_` | CMS கிளையன்ட் ஒத்திசைவு |
| `DAT_AUTH_`, `DAT_REQ_`, `DAT_STORE_` | CMS சேவையகம் |

`_UNKNOWN` ஒவ்வொரு பகுதியிலும் வேறு குறியீடாக வகைப்படுத்த முடியாத பிழைக்கு மட்டுமே. பகுதி மாறினாலும் ஒரே காரணத்திற்கு ஒரே பெயரைப் பயன்படுத்தவும்.

## மீண்டும் முயல் வகைகள்

| வகை | பொருள் | கையாளுதல் |
| --- | --- | --- |
| தற்காலிகம் | வெளி நிலை சீரானால் வெற்றியடையலாம் | பின்வாங்கலுக்குப் பின் வரம்புடன் மீண்டும் முயலவும் |
| நிலை | சான்றிதழ் ஒத்திசைவு அல்லது நேரம் மாறினால் வெற்றியடையலாம் | தேவையான நிலையைப் புதுப்பித்து மீண்டும் முயலவும் |
| நிரந்தரம் | அதே உள்ளீட்டில் மீண்டும் முயன்றாலும் தோல்வி | உள்ளீடு, அமைப்பு அல்லது குறிமுறையைத் திருத்தவும் |

## டோக்கன்கள் மற்றும் சான்றிதழ்கள்

<ErrorCode code="DAT_TOKEN_MALFORMED" impact="none" retry="permanent">
DAT-ன் புல எண்ணிக்கை, எண் அல்லது Base64Url வடிவம் விவரக்குறிப்புக்கு மாறாக உள்ளது. உள்ளீட்டை நிராகரிக்கவும்.
</ErrorCode>

<ErrorCode code="DAT_TOKEN_EXPIRED" impact="none" retry="permanent">
DAT-ன் காலாவதி நேரம் தற்போதைய நேரத்திற்குச் சமமாகவோ முந்தையதாகவோ உள்ளது. புதிய DAT தேவை.
</ErrorCode>

<ErrorCode code="DAT_CERT_MALFORMED" impact="none" retry="permanent">
சான்றிதழ் சரத்தின் கட்டமைப்பு அல்லது புல வடிவம் தவறானது.
</ErrorCode>

<ErrorCode code="DAT_CERT_NOT_FOUND" impact="none" retry="state">
DAT-ன் `cid`-க்குரிய சான்றிதழ் இல்லை. சான்றிதழ் ஒத்திசைவு நிலையைச் சரிபார்க்கவும்.
</ErrorCode>

<ErrorCode code="DAT_CERT_NOT_SYNCED" impact="none" retry="state">
பயன்படுத்த வேண்டிய சான்றிதழ் இன்னும் சேவையை அடையாமல் இருக்கலாம். உடனே ஒத்திசைத்து மீண்டும் மதிப்பிடவும்.
</ErrorCode>

<ErrorCode code="DAT_CERT_NOT_YET_VALID" impact="none" retry="state">
சான்றிதழின் தொடக்க நேரம் இன்னும் வரவில்லை. கணினி நேரத்தையும் விநியோக நேரத்தையும் சரிபார்க்கவும்.
</ErrorCode>

<ErrorCode code="DAT_CERT_EXPIRED" impact="none" retry="permanent">
சான்றிதழின் சரிபார்ப்புக் காலம் முடிந்துவிட்டது.
</ErrorCode>

<ErrorCode code="DAT_CERT_DUPLICATE" impact="partial" retry="permanent">
ஒரே இறக்குமதிப் பட்டியலில் ஒரே `cid` மீண்டும் வந்துள்ளது. முழு இறக்குமதியையும் நிராகரிக்கவும்.
</ErrorCode>

## கையொப்பம், மறையாக்கம் மற்றும் விசைகள்

<ErrorCode code="DAT_SIG_MISMATCH" impact="none" suspect retry="permanent">
கையொப்பம் உள்ளடக்கத்துடன் பொருந்தவில்லை. இது மாற்றப்பட்ட DAT அல்லது வேறு விசையால் கையொப்பமிடப்பட்ட DAT.
</ErrorCode>

<ErrorCode code="DAT_CRYPTO_TAG_MISMATCH" impact="none" suspect retry="permanent">
AES-GCM அங்கீகரிப்புக் குறி பொருந்தவில்லை. மறையுரை மாற்றம் அல்லது சான்றிதழ் பொருந்தாமையைச் சரிபார்க்கவும்.
</ErrorCode>

<ErrorCode code="DAT_KEY_INVALID" impact="none" retry="permanent">
விசையின் நீளம், வடிவம் அல்லது வழிமுறைக் கலவை தவறானது.
</ErrorCode>

<ErrorCode code="DAT_SIG_KEY_MISSING" impact="none" retry="permanent">
சரிபார்ப்பு-மட்டுமான சான்றிதழால் DAT-ஐ வழங்க முயன்றீர்கள். வழங்கும் சேவைக்கு முழுமையான சான்றிதழ் தேவை.
</ErrorCode>

`DAT_SIG_MISMATCH` மற்றும் `DAT_CRYPTO_TAG_MISMATCH` பொதுப் பாதுகாப்பு நிகழ்வு API-யால் உண்மை என வகைப்படுத்தப்படும் பிழைகள். ஒரு தவறான உள்ளீடு சேவை முடக்கம் அல்ல; மீண்டும் மீண்டும் நிகழ்ந்தால் பாதுகாப்புக் கண்காணிப்பில் வைக்கவும்.

## மேலாளர் மற்றும் அமைப்பு

<ErrorCode code="DAT_MANAGER_NO_CERTIFICATE" impact="partial" retry="state">
மேலாளரிடம் சான்றிதழ் இல்லை. சான்றிதழ்களை இறக்குமதி செய்யவோ CMS ஒத்திசைவை முடிக்கவோ வேண்டும்.
</ErrorCode>

<ErrorCode code="DAT_MANAGER_NO_ISSUABLE_CERTIFICATE" impact="partial" retry="state">
சான்றிதழ்கள் உள்ளன, ஆனால் தற்போது வழங்கக்கூடிய முழுமையான சான்றிதழ் இல்லை. காரணத் தொடரில் காலாவதி, தொடக்க நேரம் அல்லது verify-only நிலையைச் சரிபார்க்கவும்.
</ErrorCode>

<ErrorCode code="DAT_CONFIG_ARGUMENT_INVALID" impact="none" retry="permanent">
அழைப்பு வாதம் அல்லது அமைப்பு மதிப்பு அனுமதிக்கப்பட்ட வரம்பிற்கு வெளியே உள்ளது.
</ErrorCode>

<ErrorCode code="DAT_INTERNAL_UNAVAILABLE" impact="critical" retry="permanent">
தற்போதைய தளத்தில் தேவையான மறையாக்க அல்லது பிணையச் செயல்பாடு இல்லை.
</ErrorCode>

## CMS கிளையன்ட்

| குறியீடு | பொருள் | பொதுவான கையாளுதல் |
| --- | --- | --- |
| `DAT_CMS_URI_INVALID` | CMS URI வடிவப் பிழை | அமைப்பைத் திருத்தவும் |
| `DAT_CMS_UNAUTHORIZED` | அங்கீகரிப்புத் தோல்வி | டோக்கனைத் திருத்தவும் |
| `DAT_CMS_FORBIDDEN` | பங்குக்கு அனுமதி இல்லை | டோக்கன் பங்கைச் சரிபார்க்கவும் |
| `DAT_CMS_ENDPOINT_NOT_FOUND` | பாதை இல்லை அல்லது மாறுபடுகிறது | CMS முகவரியையும் பாதையையும் சரிபார்க்கவும் |
| `DAT_CMS_NETWORK` | இணைப்பு அல்லது பரிமாற்றத் தோல்வி | பிணையத்தைச் சரிபார்த்துப் பின்வாங்கவும் |
| `DAT_CMS_TIMEOUT` | நேர வரம்பு மீறல் | பிணையம் மற்றும் நேர வரம்பை சரிசெய்யவும் |
| `DAT_CMS_SERVER_ERROR` | CMS சேவையகப் பிழை | சேவையக நிலையைச் சரிபார்த்துப் பின்வாங்கவும் |
| `DAT_CMS_RESPONSE_INVALID` | வெற்றிப் பதில் வடிவப் பிழை | சேவையக-கிளையன்ட் ஒப்பந்தத்தைச் சரிபார்க்கவும் |
| `DAT_CMS_VERSION_RESET` | சேவையகப் பதிப்பு பின்னால் நகர்ந்தது | CMS தரவு மற்றும் வரிசைப்படுத்தலைச் சரிபார்க்கவும் |
| `DAT_CMS_IMPORT_FAILED` | பெறப்பட்ட சான்றிதழ்களைப் பயன்படுத்துவதில் தோல்வி | காரணத் தொடரைச் சரிபார்க்கவும் |
| `DAT_CMS_STOPPED` | நிறுத்தப்பட்ட மேலாளரைப் பயன்படுத்துதல் | புதிய மேலாளரை உருவாக்கவோ அழைப்பு வரிசையைத் திருத்தவோ வேண்டும் |

தொடக்க ஒத்திசைவு best-effort ஆக உள்ள நூலகங்கள் பிழையைக் கடைசிப் பிழைப் புலத்தில் வைக்கும். தொடக்கம் தோல்வியடைய வேண்டுமானால், பிழையை நேரடியாகத் திருப்பும் அல்லது எறியும் உடனடி ஒத்திசைவு API-ஐப் பயன்படுத்தவும்.

## CMS சேவையகம்

| குறியீடு | HTTP | பொருள் |
| --- | --- | --- |
| `DAT_AUTH_UNAUTHORIZED` | 401 | டோக்கன் இல்லை அல்லது தவறானது |
| `DAT_AUTH_FORBIDDEN` | 403 | டோக்கன் பங்கு கோரிக்கை அனுமதியுடன் பொருந்தவில்லை |
| `DAT_REQ_ALG_UNSUPPORTED` | 400 | ஆதரவற்ற வழிமுறைப் பெயர் |
| `DAT_REQ_NOT_FOUND` | 404·405 | பாதை அல்லது முறை பொருந்தவில்லை |
| `DAT_REQ_TOO_LARGE` | 413 | கோரிக்கை உடல் வரம்பு மீறலுக்கான ஒதுக்கீட்டுக் குறியீடு |
| `DAT_STORE_UNAVAILABLE` | 503 | சேமிப்பகம் தற்காலிகமாகக் கிடைக்கவில்லை |
| `DAT_STORE_UNKNOWN` | 500 | சேமிப்பகச் செயலாக்கத்தில் வகைப்படுத்தப்படாத பிழை |

தற்போதைய கிளையன்ட் 2xx-க்கு அல்லாத JSON பதிலின் சேவையகக் குறியீட்டை நேரடியாக வெளிப்படுத்தாது; HTTP நிலையை `DAT_CMS_*` குறியீடாக மாற்றும். சேவையகப் பதிவும் கிளையன்ட் பிழைக் குறியீடும் மாறுபடலாம்.

## மொழிவாரியாக சரிபார்ப்பது

| சூழல் | பிழைக் குறியீடு | மீண்டும் முயல் வகை |
| --- | --- | --- |
| Rust | `err.code()` | `err.retry()` |
| Go | `dat.Code(err)` | `dat.Retry(err)` |
| JavaScript / TypeScript | `error.code` | `error.retry` |
| Python | `error.code` | `error.retry` |
| Ruby | `error.code` | `error.retry` |
| Java / Kotlin | `error.code` | `error.retry` |
| C# | `error.Code` | `error.Retry` |
| C / C++ | `dat_error_code(error)` | `dat_error_retry(error)` |
